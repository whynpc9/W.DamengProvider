## 历史术语与状态

- “候选”指当时受测的某一份源码或包，不是当前版本。
- “冻结”“窗口”“root/High/Low”“approval”描述当时的协作和输入控制，不构成当前审批流程。
- “未实施”“停止”“待验收”只表示当时状态；当前能力以最新兼容文档为准。
- 模型名、工具名和角色名只用于解释原记录，不指定当前人员或工具，也不授予数据库、发布或权限维护操作。
