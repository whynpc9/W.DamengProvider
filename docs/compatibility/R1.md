# 基础兼容边界

本项目为 .NET 6/8/9/10 ADO.NET provider，包和程序集名为 `W.DamengProvider`，公开命名空间为 `W.Dm`，生产项目不依赖 EF。旧 `DM.DmProvider` 或 `W.DmProvider` 引用需要显式迁移依赖并重新编译，不能按程序集同一性替换。

默认要求完整 TLS；不提供自动重连、请求重放、分布式事务或原生批量装载。真实 profile 分别验证，不从单个服务器或固定 EF 套件推导通用兼容。当前已实现异步、容量调度和流式 LOB；具体契约见 [R2](R2.md)、[R3](R3.md)、[事务](T10-transactions.md)和[时间精度](TP-temporal-precision.md)。

当前包的身份与验证范围见 [0.2.0 发布记录](../release-0.2.0.md)，包含 [issue #16 修订](I16-ef-integration-feedback.md)。原 [0.1.0-preview.1](../release-0.1.0-preview.1.md) 仅保留其自身发布验收。

## 基础兼容变化

SQL 参数和事务守卫使用 R1 已验收 profile 的非嵌套块注释语法；不会让第二个语句藏在深度计数内。整数 typed getter 对 SQL NULL 报转换错误，真实零值不变。CLOB null-buffer 长度探测返回 decoded UTF-16 长度且不消费顺序位置；完整物化上限固定 64 MiB（67,108,864 字节）：BLOB byte[] 按字节数，CLOB string 按 UTF-16 payload 字节数（2×字符数），BLOB 十六进制 string 按 4×输入字节数计。已知超限在读取/分配前拒绝，不静默截断；定位符单位和保守预检查细节见历史 R1 报告。这是值的大小限制，不是进程总内存上限；流式接口另见 [R3](R3.md)。

Connection=null 清理本命令的连接及 statement 状态。活动执行/Reader、显式 active command.Transaction 或原物理会话正被其他 owner 使用时，连接变更快速失败并保留原绑定；调用方可先清 command.Transaction，事务对象仍由原连接管理。重新绑定后重新准备语句，不复用旧连接句柄。

显式本地事务中，已验证 profile 允许严格单条用户/EF 保存点 SQL，驱动服务器名称前缀 WSP_（含大小写、引号、注释变体）保留并拒绝用户触及。SQL 原文不改写；成功执行确认后更新 API/raw 统一有序栈。已知 raw 回滚/释放失效其后继 API 点；名称大小写/引号有歧义或成功目标未知时保守清空跟踪栈，不保留可能过期的 API 点。Prepare 和失败执行不更新栈；完整 COMMIT/ROLLBACK、参数化或复合保存点控制仍拒绝。总栈和 API 序号各以 128 为限。SQL NULL 的 typed getter（含 GetGuid/GetFieldValue<T>）使用 DmException 6081；GetValue/GetFieldValue<object>/GetFieldValue<DBNull> 仍返回 DBNull。TLS 认证失败维持固定外层消息，原握手原因保留为 InnerException。
