# 异步与取消契约

当前版本为 `0.3.0`；本页历史阶段证据仍归原候选，当前发布状态与验证范围见[发布记录](../release-0.3.0.md)。

本页记录 R2 阶段建立的异步与取消契约；当时目标为 net10.0，0.2.0 已扩为 net6.0/net8.0/net9.0/net10.0，均不依赖官方 DLL。后续数据源与流式 LOB 行为见 [R3](R3.md)；当前发布状态见 [progress.json](../implementation/progress.json)。具体测试结果归属其受测版本，发布证据见发布记录。

| 入口/边界 | R2 契约 |
| --- | --- |
| Open/Prepare/Execute/Read/NextResult | async 网络调用贯通，不使用 Task.Run 或基类同步 I/O fallback；缓存允许立即完成 |
| 本地事务/保存点/网络清理 | 异步协议与有限 cleanup；保存点仅 8.1.5.60，TLS 8.1.4.6 明确发送前拒绝 |
| BLOB/CLOB | 支持异步物化与流式读写，完整物化仍受 64 MiB returned payload 上限；生命周期见 [R3](R3.md) |
| token | 本次 invocation 生命周期；ExecuteReader 成功返回后旧 token 解绑，后续 Read 使用新 token |
| Command.Cancel | 当前冻结 execution/reader；inactive no-op，旧身份不能取消新执行 |
| Reader.IsClosed / Dispose | 会话失效可先返回IsClosed=true；仍需无条件Close/Dispose释放lease与command plan，之后命令设置才可修改 |
| 发送前取消/期限 | 零网络副作用，会话/Active 事务及既有 prepared handle 保留 |
| 发送后取消/期限 | AbortPhysicalSession，Broken，不透明重连、重放或回池；服务器是否已停止独立观察 |
| Commit 失确认 | OutcomeUnknown 优先，不建议自动重试；已完整验证的 ACK 固化终态 |
| deadline | Connect 总预算；每次 public Execute/Reader 调用一个冻结预算，内部 Fetch/chunk/heartbeat 不重置；cleanup 有限且独立 |
| metadata | Connection.GetSchemaAsync 使用真正异步目录查询及清理（[I10](I10-metadata.md)）；Reader.GetSchemaTableAsync 仅缓存 |
| 未开放能力 | 复杂参数、游标输入和物理会话复用；受管输出游标见 [I09](I09-stored-procedures.md)；容量调度与 streaming 已实现，见 [R3](R3.md)；数组绑定与 DbBatch 见 [I07/I08](I07-I08-array-binding-dbbatch.md) |

| 本地符号 | 类型/公开分类 | 服务端 Number |
| --- | --- | --- |
| WDM_TIMEOUT | DmTimeoutException / Timeout，当前报告 TotalDeadline；IdleTimeout 枚举保留 | 0（没有伪造服务端错误） |
| WDM_CANCELED | DmOperationCanceledException / Canceled，保留原 token 与首 CancelSource | 不适用 |
| WDM_COMMIT_UNKNOWN | DmCommitOutcomeUnknownException / OutcomeUnknown，Commit/Unknown/不可复用；保留首 CancelSource 与 InnerException | 0 |
| WDM_TRANSPORT | DmException / Transport，实际阶段，发送前 NotSent、发送后 Unknown，不可复用；原 socket 异常为 InnerException（[issue #16](I16-ef-integration-feedback.md)，未随 0.1.0-preview.1 发布） | 0 |

FailureInfo 只包含稳定分类、阶段、操作/事务结果、是否可复用及确实存在的服务器错误号，不含 SQL、连接串或认证报文。完整原始失败和修复轮分别保存，不把历史失败重写为通过。

BEGIN 的 configuration、cleanup、activation 使用各自故障阶段；发生在新阶段创建前的取消/到期按原异常和token分类，不能使用已完成的configuration invocation替代。FailureInfo.OperationOutcome描述失败子阶段是否发送；BEGIN早先已发送时，即便activation为NotSent，TransactionOutcome仍可为OutcomeUnknown且连接不可复用，不能据此建议重试。CommitUnknown保留确实已知的ServerErrorNumber；未获服务器码时保持null。

0.3.0 的现代四目标与受限 Standard 2.1 资产分开判断；旧资产无 TLS、DbBatch、DateOnly/TimeOnly 映射，具体差异见[旧目标说明](core31.md)。
