# T14 runner

> 历史专项复现入口，不是当前发布流程。只消费已审查的精确候选包，实库仍须核验 TEST 身份、保留失败记录并精确清理。当前能力见[文档导航](../docs/implementation/README.md)。

由验证者对已审查的候选运行：

```sh
eng/t14.sh shared <exact-version> <absolute-local-package-feed>
eng/t14.sh tls <exact-version> <absolute-local-package-feed>
```

可设置 `DOTNET_COMMAND` 为已安装且满足 global.json 的 SDK 命令。runner 设置独立 writable cli-home、NuGet cache/bin/obj，禁用 first experience/telemetry，使用单节点、noReuse、noSharedCompilation、disable-build-servers，不清 global cache、不重打产品包。所有新记录在 `.local/verification/r2/t14/runs/...`，保留每轮 build/probe/validation/package hashes；不回写 T13 已接受输入。

主验收 shared 包含 8 个功能 case 与 8/16 独立连接 rowlock 性能观测；TLS 包含相同 8 个边界 case，PER 限定 shared 范围。数字 send barrier、typed first-cause/Unknown、无重放/自动重连、old token/session 隔离、fresh 数据库最终状态与精确对象 absence 都是硬门。工具不发送 native cancel，不宣称服务器即时停止，也不以延时采样替代异步 pending gate。

详细边界与证据限制见 [R2CancellationProbe](../tools/R2CancellationProbe/README.md)。本文描述工具验收方式，不代表本次已运行；结果按实际候选分别记录。
