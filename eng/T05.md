# T05 session acceptance commands

`blob` is a historical comparison mode and is retired. Use the current package smoke consumer for BLOB validation; ordinary `offline` and W `real` modes build directly from product source.

`eng/t05.sh offline` restores and runs `W.DmProvider.SessionTests` and builds `SessionProbe`. It accepts a run only when the TRX reports every test executed and passed, with every failure, skipped, aborted, pending, or other nonpass counter at zero. A successful offline run reports `integration_pending`.

`eng/t05.sh real` builds `SessionProbe`, then invokes it only through `scripts/with-dameng-test.sh`. The probe verifies `WDM_PROVIDER_TEST` and the current Schema after each Open, sets `TransportSecurity=PlaintextAllowed` using the typed W builder, and suppresses raw exceptions and stderr. It creates one unique unqualified `T05_` table, drops only that table in `finally` style cleanup, and checks `USER_TABLES` from a fresh connection. The JSON result names the W implementation and the final server state. It checks reader ownership and zero send on rejected operations, same reader child invocation, transaction conflicts and stale transaction rejection, after send and before decode faults, two simultaneous physical wire exchanges, old Close versus new Open, handshake Close, state callback lock freedom, a 96 KiB BLOB through GetBytes and Stream, metadata paths, and idempotent Close.

The offline suite uses internal session test hooks for deterministic ownership, stale identity, broken wire exchange, overflow, separate session barriers, and every inventoried wire entry guard. These hooks do not send protocol bytes. The real probe covers public behavior with actual server responses. The source inventory at `docs/implementation/T05-wire-inventory.md` maps legacy and MSG entries; a passing probe alone cannot prove unlisted entries.

Every run has a fresh ignored `.local/t05/runs/<id>` directory. The script sets a writable `DOTNET_CLI_HOME`, disables first-run behavior and telemetry, and builds with one MSBuild node, no node reuse, no shared compilation, and disabled build servers. Failed stages emit a structured rejection with the command exit code; a failed real probe never emits a success result.
