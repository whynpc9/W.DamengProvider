# 本地事务与保存点验证

> 历史专项复现入口，不是当前发布流程。执行前确认固定输入和服务器能力；实库仍须核验 TEST 身份并精确清理。当前事务行为见[事务说明](../docs/compatibility/T10-transactions.md)。

```sh
bash eng/t10.sh offline
bash eng/t10.sh real
```

`offline` 运行 TransactionTests，严格核对全部执行、全部通过、零 skip/abort 的 TRX，构建候选探针并执行 T08 离线回归；结果保留 integration_pending。`real` 通过 TEST wrapper 运行候选场景并执行 T08 实库回归，确认用户/Schema 为 WDM_PROVIDER_TEST、只操作本轮唯一对象、清理后由新连接确认不存在。

场景覆盖 Commit/Rollback、终态 Dispose、Active Dispose 与 Reader、所有权与旧会话、公开旧字段篡改、发送前/发送后/ACK 竞态、保存点映射、后续 SQL 错误、已验证 profile 的 TABLE DDL CompletedExternally、默认 ReadCommitted 与 ambient 边界。严格错误体解析、共享 cleanup deadline 和不支持 DDL 的发送前拒绝由相应离线测试覆盖。隔离级别矩阵另见 [T11](T11.md)。

`baseline` 仅用于官方驱动与固定旧 W 二进制的历史表征，依赖原本机资产，输出 baseline_profiled 不代表当前候选通过。没有独立 BEGIN opcode；本地 Active 与服务器业务操作状态必须区分，关闭 socket 也不能冒充回滚 ACK。当前事务契约见[兼容说明](../docs/compatibility/T10-transactions.md)。

runner 保存每轮命令、退出码、源标识和结果；按 AGENTS.md 设置 DOTNET 环境与单节点参数。旧失败记录保留在各自 ignored 目录，不把旧失败、代码准备完成或本文断言写成当前验证结果。
