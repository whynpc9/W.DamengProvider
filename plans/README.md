以下方向没有进入首批实施：物理连接直接复用、旧目标框架的明确功能限制、顺序 `DbBatch`、过程事务限制，以及没有生产可达证据的遗留分支。完整理由见审查报告，后续调查前先核对，避免重复工作。

历史测试数量只证明当时提交；关闭自动依赖审计也不被当作已知 CVE。
